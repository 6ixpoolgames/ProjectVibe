# Project Base

A reusable base for real-time 3D games in Godot 4.7: pawns that a player or an AI can drive, abilities built from steps, AI that senses and decides, navigation, networked play with rollback, streaming worlds, replays and diagnostics.

Built for designers first: sensible defaults, settings in the inspector, and clear warnings when something's missing.
